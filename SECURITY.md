# Security policy

Report a vulnerability privately to Knitli Inc. at <knitli@knitli.com>. Do not open a public issue for a suspected vulnerability.

Please include what you found, how to reproduce it, and which package and version it affects. We will acknowledge the report and coordinate a fix and disclosure with you.

Only the latest published version of each package is supported.
