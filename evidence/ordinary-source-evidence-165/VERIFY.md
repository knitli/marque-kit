# Ordinary source evidence in the Word pane

The DOM cases use a synthetic, trusted Word host and the real ordinary CAB
questions and preview WebAssembly operations. The fixture places source material
in the selected classified paragraph, separately from the target authority block,
with byte-accurate observation and group spans. Source instruction and protected
value identities differ from both hypothetical target answer references.

Date and event source observations paired with a protected classifier observation
permit an authorized hypothetical preview while the current target's Classified
By and Classification Reason fields remain missing. Unknown instruction and
protected observations withhold that preview. A source grant revocation clears a
visible result; changing the source grant while apply is pending prevents the
late result from appearing. No source text or opaque references appear in the
DOM or raw engine output. These are synthetic-host results, not live Word
qualification or proof of a write, value validity, or document readiness.

From `packages/kit`, set `MARQUE_165_WASM` to a Node-compatible WASM package
entry and run `vp test test/dom/ordinary-source-evidence-165.test.ts`. The
provisional run passed 6/6 using entry SHA-256
`e6ffaacb4f348a1d187afb276672f1d31554cb9388103054fdfbb31e0844cc0a` and binary
SHA-256 `c67cf30ce1608cf35069171a1ce7eb4b8f73222d5c556a265ee19d65a907280f`.
The product was copied to a temporary CommonJS package; no artifacts or local
`node_modules` symlinks are included. A final matched-engine replay is pending.
