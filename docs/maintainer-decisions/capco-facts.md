# CAPCO facts the examples rely on

All documents and markings in this repo are fictional examples.

These are passages from CAPCO-2016 that the memo (`fixtures/`) and the docs cite. Each was verified against the manual. They are reference, not decisions. Verify a citation again before using it somewhere new.

- USA is always a co-owner in a JOINT list (§H.3 p55). JOINT is not carried to the banner of a U.S. document; the banner carries FGI with the co-owner codes (§H.3 p57). The maintainer notes p57 reads misleadingly here: JOINT can be a banner, but not here, because like non-U.S. classification it yields to unilateral U.S. classification.
- REL TO codes are separated by a comma and a space (§H.8 p151). NOFORN "cannot be used with REL TO, RELIDO, EYES ONLY, or DISPLAY ONLY" (§H.8 p145); a NOFORN portion puts NOFORN in the banner (§H.3 p57).
- Every portion is marked (§C p25). The authority block is `Classified By / Derived From / Declassify On`, dates `YYYYMMDD` (§E p31, §E.2 p32). The banner carries the highest classification of any portion (§D p28).
- EO 13526 §1.4 lists eight classification categories, (a)–(h); an original classifier's reason must be one or more of them.
